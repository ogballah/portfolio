Projects and Assignments

Project 1 - Cloud-Based SSH/Telnet Honeypot & Threat Intelligence Collection

Deployed a Cowrie SSH/Telnet honeypot on AWS EC2 (Ubuntu Server 24.04 LTS), using security groups and iptables NAT for public access while limiting management to a single IP. It captured 17+ attack sessions from 14+ IPs in the first week, including 65+ commands and malware attempts. I also fixed a systemd socket-activation issue and built an HTML/CSS/JavaScript dashboard to display the Cowrie logs.

Project 2 - Advanced Enterprise Network Design, Automation, and Monitoring

Designed a multi-building network with 30+ endpoints, using subnetting, VLANs, inter-VLAN routing and access control to create 5+ isolated segments. Wrote Python scripts to verify connectivity, latency and uptime across 25+ devices and 10+ routing, segmentation and failover scenarios.

Project 3 - Four Cities Network Design

I configured and mapped the design for a network connecting four cities, namely Chicago, Los Angeles, New York, and Miami. The network diagram shows how different sites were connected to each other.

Project 4 - Movie Theater Ticketing System

I developed a movie theater ticketing system in Python, where a user selects a movie and buys tickets. It helped me to apply the basic concepts of programming learned in class.

Project 5 - Five Letters Word Guessing Game

I made a Python mini-game, which randomly selects a five-letter word for the player to get it right in 7 attempts or less.
